# 🐦🚲 鹈鹕骑行记 · Pelican on a Bicycle 3D

一只大白鹈鹕骑着复古薄荷绿自行车环湖骑行的实时 3D 交互页面。单个 HTML 文件，所有模型、纹理、音乐、音效都由代码实时生成。

**在线体验：** https://strawberry040607.github.io/pelican-bicycle-3d/

## 🎮 自由驾驶模式（新！）

按 `WASD` / 方向键（手机上用虚拟摇杆）随时接管鹈鹕：

- **骑行物理**：加速、刹车倒车、按速度变化的转向半径、压弯倾斜、上下坡受重力影响，`Shift` 冲刺
- **跳跃 & 飞行**：`空格` 跳跃；空中再按＝扇翅膀（最多 3 次），长按＝张开翅膀滑翔
- **特技系统**：空中 `A/D` 转体、`W/S` 前后空翻，落地摆正才算成功（转体 +120、空翻 +250、组合 ×2），没摆正就会摔车
- **跳台**：赛道旁、野外，还有两座冲向湖面的大跳台
- **收集**：32 条金鱼散落在跳台的飞行弧线上、湖面上空、赛道边和山坡上，集齐会放烟花；穿过圆环 +150
- **碰撞**：撞到树、路灯、岩石会弹开，速度太快会直接摔车；冲进湖里就变成「划水模式」
- `X` 回到赛道，`G` 切回自动骑行

## ✨ 特性

- **程序化鹈鹕**：泪滴形身体、渐细 S 形脖子、可开合的长喙和会鼓起来的喉囊、会眨的眼睛、羽冠、黑色飞羽
- **双骨骼 IK**：双腿实时踩踏板，翅膀握住车把（还能松开挥手）
- **完整的自行车**：32 根辐条的轮子、齿轮、会转的链条、曲柄、弹簧车座、车铃、车灯（夜晚会亮）、车筐里装着鱼、尾旗随风飘
- **物理感**：转弯会压弯倾斜，上坡减速，下坡滑行（能听到飞轮的咔哒声）；鹈鹕的头像真鸟一样保持水平
- **昼夜循环**：Sky 大气散射、动态太阳/月亮、星空、萤火虫、路灯、PMREM 环境反射
- **世界**：起伏地形、带反射的湖、跳出水面的鱼和涟漪、睡莲、上千棵树和随风摆动的草、花、云、天上 V 字队形飞过的鹈鹕群、起点拱门
- **后处理**：MSAA + UnrealBloom + ACES 色调映射 + PCF 软阴影
- **程序化音频**（Web Audio）：风声、轮胎滚动声、跟着踏频走的五声音阶音乐、车铃、鹈鹕叫声、吞咽声、鸟鸣、蟋蟀、溅水声
- **5 种镜头**：自由环绕 / 追随 / 侧面跟拍 / 电影运镜（自动切换 6 个机位）/ 鹈鹕视角
- **互动**：点击鹈鹕、按铃、喂鱼、挥手、截图、录制带声音的 6 秒视频、小地图、lil-gui 控制面板

## 🎮 操作

| 按键 | 功能 |
|---|---|
| 鼠标拖拽 / 滚轮 | 旋转 / 缩放（自由环绕模式） |
| 点击鹈鹕 | 叫一声并抖落羽毛 |
| `WASD` / 方向键 | 自由驾驶 |
| `空格` / `Shift` | 跳跃·扇翅膀·滑翔 / 冲刺 |
| `G` / `X` | 切换自动/自由 / 回到赛道 |
| `1`–`5` | 切换镜头 |
| `B` `F` `E` | 按铃 / 喂鱼 / 挥手 |
| `T` / `P` | 快进 3 小时 / 暂停 |
| `C` / `R` | 截图 / 录像 |
| `M` / `U` / `H` | 静音 / 隐藏界面 / 帮助 |

URL 参数：`?t=20`（固定时间）、`?cam=cinematic`（初始镜头）、`?auto`（跳过开场）、`?free`（直接进入自由驾驶）。

## 🛠 技术

three.js r165（通过 jsDelivr CDN 加载）· lil-gui · Web Audio API · MediaRecorder · 纯原生 ES Modules，无需构建。
